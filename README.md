# PolicyPal Final Project

PolicyPal is an AI-powered HR policy Q&A assistant developed for the COIT13232 Business Analysis Project.

The system allows employees to ask HR policy questions and receive grounded answers based on the approved employee handbook, including section references and escalation to People & Culture when a question requires personal, legal, medical, or case-specific information.

## Main Features

- HR policy question answering
- Claude API integration
- Handbook-grounded responses
- Section citations
- Automatic escalation for out-of-scope questions
- Next.js frontend and backend API route

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Anthropic Claude API
